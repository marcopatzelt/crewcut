# Code of conduct

We want Crewcut to be a friendly place to build things. Everyone who takes part in this project (issues, pull requests,
discussions, any other space of the project) agrees to these rules.

## What we expect

- Be kind and patient. Assume good intent. Many contributors write in their second language.
- Talk about the work, not the person. Critique code and ideas with reasons.
- Accept a "no" on a proposal gracefully; ask what would make it a "yes".
- Credit other people's work.

## What we do not accept

- Harassment, insults, discrimination or sexualised language, in public or in private messages.
- Publishing other people's private information.
- Spam, including promotion of unrelated products, tokens or coins.

## Enforcement

Report problems to the maintainer through GitHub (a private vulnerability report works for anything sensitive). The
maintainer reviews every report, keeps the reporter's identity private, and may warn, remove content or ban a person
from the project. This code of conduct is adapted in spirit from the Contributor Covenant, version 2.1.
