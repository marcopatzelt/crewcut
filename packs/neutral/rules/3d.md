# Rules for 3d

- 2026-11-16: Every 3D object does something from the first frame; nothing just stands there. (source: Crewcut default)
- 2026-11-16: A still frame at half size, next to the reference, comes before any animation render. (source: Crewcut default)
- 2026-11-16: The cost estimate comes before renting; the user says yes to the money. (source: Crewcut default)
- 2026-11-16: Rented machines get only scene code and fonts, never footage, keys or private data. (source: Crewcut default)
