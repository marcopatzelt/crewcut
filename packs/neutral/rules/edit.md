# Rules for edit

- 2026-11-16: Plan inserts from word anchors in the transcript, never from typed seconds. (source: Crewcut default)
- 2026-11-16: Show something happening before showing text; a text card only where the viewer must read a real source. (source: Crewcut default)
- 2026-11-16: The number or word in a scene lands on the spoken word, 0 to 3 frames before it. (source: Crewcut default)
- 2026-11-16: Music stays under the voice, never ends before the video, and has a source and rights note. (source: Crewcut default)
- 2026-11-16: Every change after the user has seen a file is a new plan version. (source: Crewcut default)
